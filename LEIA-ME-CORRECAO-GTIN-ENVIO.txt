CORREÇÃO DO ENVIO DE GTIN / MOTIVO DE AUSÊNCIA - MERCADO LIVRE

O que foi corrigido:
- EMPTY_GTIN_REASON agora usa value_id quando o Mercado Livre fornece uma lista oficial de valores.

Instalação:
1. Copie a pasta lib para a raiz do projeto e substitua o arquivo existente.
2. git add .
3. git commit -m "Corrige envio de GTIN ao Mercado Livre"

Não é necessário executar SQL no Supabase.
