CORREÇÃO 2 - OAUTH MERCADO LIVRE / DOMÍNIO VERCEL

O erro foi identificado: o painel estava sendo aberto em https://virella-sexshop.vercel.app.
Esse domínio não pode criar um cookie pertencente a .virellasexshop.com.br.
Por isso, após autorizar no Mercado Livre, o callback não encontrava o state do OAuth.

1. Copie as pastas app e lib para a raiz do projeto e substitua os arquivos.
2. Na Vercel, crie/edite também:
   MERCADO_LIVRE_SITE_URL=https://www.virellasexshop.com.br
3. Confirme:
   MERCADO_LIVRE_REDIRECT_URI=https://www.virellasexshop.com.br/api/mercado-livre/callback
4. Faça novo deploy.
5. NÃO abra o admin pelo endereço *.vercel.app.
   Use sempre:
   https://www.virellasexshop.com.br/admin/mercado-livre
6. Faça login no admin nesse domínio e clique em Conectar Mercado Livre.

Com esta correção, se alguém tentar iniciar o OAuth pelo domínio da Vercel,
o sistema redireciona primeiro para o domínio oficial antes de criar o cookie de segurança.
