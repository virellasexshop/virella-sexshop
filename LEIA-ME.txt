CORREÇÃO DA GRADE MOBILE NAS PÁGINAS DE CATEGORIA

1. Copie a pasta app para a raiz do projeto.
2. Confirme a substituição de app/globals.css.
3. Execute:
   git add app/globals.css
   git commit -m "Corrige duas colunas nas categorias no celular"
   git push

A correção altera a classe correta usada pela página /categoria/[slug]: .catalogGrid.
