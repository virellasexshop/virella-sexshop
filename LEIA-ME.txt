CORREÇÃO OAUTH MERCADO LIVRE

Motivo provável: o fluxo de autorização começou em virellasexshop.com.br e voltou para www.virellasexshop.com.br. O cookie de segurança OAuth era restrito ao host, então o callback não encontrava o state e mostrava "Autorização inválida ou expirada".

A correção compartilha o cookie OAuth entre o domínio raiz e www e só remove o cookie após validar corretamente o retorno.

Copie a pasta app para a raiz do projeto e substitua os dois arquivos.

Depois:
git add app/api/mercado-livre/auth/route.js app/api/mercado-livre/callback/route.js
git commit -m "Corrige OAuth Mercado Livre"
git push

Após o deploy:
1. Faça login no admin da Virella primeiro.
2. Abra /admin/mercado-livre.
3. Clique em Conectar Mercado Livre.
4. Autorize novamente no Mercado Livre.
