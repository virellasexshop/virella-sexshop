AJUSTES DO PAINEL DE PEDIDOS

Incluído:
- filtro "Todos";
- filtro "Hoje";
- escolha de uma data específica;
- contador de resultados filtrados;
- itens do pedido clicáveis;
- janela de detalhes do item com imagem, variação, quantidade, preço unitário e total.

INSTALAÇÃO
1. Extraia este ZIP.
2. Copie as pastas app e modules para a raiz do projeto.
3. Confirme a substituição dos arquivos.
4. No terminal, execute:

   git add app/admin/pedidos modules/orders/order.service.js
   git commit -m "Adiciona filtros e detalhes aos pedidos"
   git push

A Vercel fará o deploy automaticamente.
