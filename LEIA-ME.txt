META PIXEL — ETAPA 1 (PAGEVIEW)

Pixel configurado: 866337403001309

Arquivos:
- app/layout.js
- components/MetaPixel.js

COMO INSTALAR
1. Abra a pasta raiz do projeto no computador.
2. Copie a pasta app deste pacote para a raiz e confirme a substituição de app/layout.js.
3. Copie a pasta components para a raiz. Isso adicionará components/MetaPixel.js.
4. No terminal, execute:
   git add app/layout.js components/MetaPixel.js
   git commit -m "Instala Meta Pixel e PageView"
   git push
5. Aguarde o deploy automático da Vercel.

O QUE FOI FEITO
- Carrega o script oficial do Meta Pixel.
- Inicializa o Pixel 866337403001309.
- Dispara PageView ao abrir o site.
- Dispara PageView nas navegações internas do Next.js.

TESTE
Depois do deploy, no Gerenciador de Eventos da Meta:
Fontes de dados > Virella Pixel > Testar eventos.
Abra o endereço do site em outra aba e navegue por algumas páginas.
O evento PageView deverá aparecer.
