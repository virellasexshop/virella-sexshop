CORREÇÃO GTIN / MERCADO LIVRE

Esta versão corrige a falsa opção de publicar sem GTIN em categorias que o endpoint /items continua tratando como GTIN obrigatório.

Arquivos alterados:
- app/api/mercado-livre/category-attributes/route.js
- app/admin/mercado-livre/MercadoLivreManager.jsx
- lib/mercado-livre/products.js

Como instalar:
1. Copie as pastas app e lib para a raiz do projeto.
2. Substitua os arquivos existentes.
3. git add .
4. git commit -m "Corrige exigencia real de GTIN Mercado Livre"
5. git push

Depois do deploy, abra o produto e clique novamente em Conferir ID.
Se a categoria realmente exigir GTIN, a opção de ausência deixará de aparecer e a publicação será bloqueada antes de chamar a API.
