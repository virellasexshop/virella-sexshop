# Grade com dois produtos no celular

Esta atualização altera somente a exibição das vitrines de produtos.

No celular, passam a aparecer dois produtos por fileira em:

- página inicial;
- catálogo completo;
- páginas de categorias.

Os cards também ficam mais compactos no celular para preservar nome, preço,
imagem e botão sem cortar conteúdo.

## Instalação

Copie a pasta `components` deste pacote para a raiz do projeto atual e confirme
**Substituir os arquivos no destino**.

Depois envie a atualização:

```powershell
git add .
git commit -m "Exibe dois produtos por fileira no celular"
git push
```

Não é necessário executar nenhum código no Supabase nem adicionar variáveis na
Vercel.
